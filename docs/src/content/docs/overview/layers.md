This repository is **not a full AUTOSAR stack** — it is a Vector CANbedded
(SIP) delivery covering the Basic Software communication/diagnostics subset
for one ECU/derivative. The table below maps every top-level directory to an
AUTOSAR-style layer.

## Top-level layout

```text
BSW/            C sources of the delivery (all Vector, see Origin page)
  Can/          MCAL — DCAN driver for TMS470/TMS570
  VStdLib/      MCAL library — compiler/CPU abstraction, interrupt control
  Il/           ECU Abstraction / COM — Interaction Layer (Il_Vector)
  Tp/           Communication Services — ISO 15765-2 transport protocol
  Nm/           Communication Services — indirect NM (OSEK) + PSA Station Manager
  Xcp/          Services — XCP protocol + XCP-on-CAN transport, app template
  _Common/      Common — v_def.h platform/type definitions
  SipVersionCheck/  Common — SIP version-consistency check (ROM constants)
Doc/            Original Vector documents (PDF/HTML/TXT, all converted to Markdown)
  ApplicationNotes/  6 × AN-ISC-* notes
  TechnicalReferences/  9 × Technical References (one per component)
  UserManuals/  6 × manuals / getting-started guides
  DeliveryInformation/  licence addendum, delivery/test reports, readme
Generators/Components/  GENy / DaVinci-era generator plugins (*.dll), PreConfig, version.info
Misc/Diagnostics/  PSA UDS diagnostics description (*.cddt) + persistor setup tool
docs/           This Astro Starlight site (not part of the firmware build)
```

## Layer classification

| Directory | AUTOSAR-style layer | Role |
| --------- | ------------------- | ---- |
| `BSW/Can` | MCAL (CAN driver) | DCAN low-level + HLL; mailbox handling, bus-off, sleep |
| `BSW/VStdLib` | MCAL (library) | Mem copy/set, interrupt suspend/restore incl. Cortex-M3 ASM |
| `BSW/Il` | ECU Abstraction (COM) | Signal-based Tx/Rx, cyclic/event transmission, timeouts |
| `BSW/Tp` | Communication Services | ISO 15765-2 segmentation/reassembly, multi-connection |
| `BSW/Nm` | Communication Services | Indirect NM (OSEK) + PSA Low-Speed Station Manager |
| `BSW/Xcp` | Services | XCP V1.0 slave (DAQ/STIM, CAL/PAG, programming) + CAN transport |
| `BSW/_Common` | Common | `v_def.h` types/qualifiers shared by all CANbedded modules |
| `BSW/SipVersionCheck` | Common | Compile-time SIP version consistency + ROM version constants |
| `Generators` | Configuration tooling | GENy plugins that generate `*_inc.h` / config from the DBC |
| `Misc/Diagnostics` | Diagnostics tooling | CANdesc `.cddt` database + persistor installer |

## What is intentionally absent

- **Application Software (ASW)** and **Complex Device Drivers (CDD):** no
  application code ships in this SIP — see [ASW / CDD](/modules/asw-cdd/).
- **RTE / OS / MCAL beyond CAN:** no RTE, no OS, no ADC/DIO/FLS drivers.
- **Generated configuration (`GenData`):** `_can_inc.h` / `_il_inc.h` are
  placeholders — the real files are generated by GENy from the DBC + `.pco`.
